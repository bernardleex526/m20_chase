# Generic CHAMP Gazebo dynamics

These seven authored fixtures reproduce the isolated ROS 2 Humble / Gazebo Classic 11 quadruped validation. They are **not an M20/Go2 model or hardware acceptance**. The earlier canonical run observed 9/9 scenario passes; see [VALIDATION.md](VALIDATION.md) for measured results and limitations. Relocation checks do not constitute a new dynamics run.

## Run

Prerequisites: Ubuntu 22.04, ROS 2 Humble, `git`, `colcon`, and this repository built with its `install/setup.bash` available. Run from the repository root:

```bash
bash simulation/gazebo/setup.sh
bash simulation/gazebo/run.sh "$HOME/.cache/m20_chase/gazebo-results/near-field"
```

`SIM_WS` defaults to `$HOME/.cache/m20_chase/gazebo_ws`; set it consistently for setup and run to use another **external** workspace. Setup pins [CHAMP 049b33ccaf77847bbea168cbb0a11c260ce119cd](https://github.com/chvmp/champ/tree/049b33ccaf77847bbea168cbb0a11c260ce119cd) and its recursive submodules (libchamp `8c50f649b3fd28a123beaf6f9618ddfaa1589559`, BSD-3-Clause). No upstream SDK, generated URDF or build products are bundled. Setup requests additive apt dependencies with `--no-remove`; package candidate conflicts must be resolved locally, especially matching libdw/libelf runtime and development versions. It does not mandate the original host's backport versions.

Run sources Humble, CHAMP and repository installs, uses DDS domain 73 and Gazebo master port 11374 unless overridden via `ROS_DOMAIN_ID`/`GAZEBO_MASTER_URI`, and interrupts its owned launch process group on exit. Do not share its DDS domain with hardware. Output defaults outside Git and contains runtime JSON, CSV, plots and logs generated by `scenarios.py`; these artifacts are not bundled. Choose a fresh output directory for each run. The launch expands the colocated xacro directly, including real CPU VLP-16 rays with `min_range=0.3m`.

## Boundaries

The actual chain is sensor cloud → rs_follow → watchdog/clamping Twist adapter → CHAMP gait → effort joints → Gazebo contacts. The target/obstacle fixtures may move; robot pose is not teleported or integrated from cmd_vel. Generic CHAMP has upstream warnings and a contact plugin Boost mutex assertion on shutdown (exit -6), despite all recorded owned processes ending. Raw follow smoother overshoot remains observed (0.21560m/s); the simulation adapter caps actual output at 0.20m/s rather than claiming the algorithm defect is fixed. Small drift measurements are limited by ground-truth noise and sampling. No hardware, ARM deployment or stricter timing guarantee follows from this evidence.
